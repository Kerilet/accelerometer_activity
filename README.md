# Accelerometer activity - Development of a Graphic Interface for the readings from the Accelerometer

This project was made as a submission to the following challenge proposed by Professor Gustavo Ferreira Palma:

Based on the accelerometer reading app developed in class, create a graphic interface using Jetpack Compose and Material Design's concepts presetend on the subject:

**1. Contents of the Interface**

The interface shall contain and exhibit, in real time, the following information:   

- X axis acceleration values;
- Y axis acceleration values;
- Z axis acceleration values;
- Device linear acceleration;
- Gravity acceleration;

The above values shown should be clearly identifiable, as well as having their respective units of measure when applicable.

**2. Guidelines**

During development, the UI and UX concepts that were discussed in class need to be considered, especially:

- Visual Information Hierarchy;
- Related Information Grouping;
- Typography;
- Spacing and Alignment;
- Adequate use of colors;
- Contrast and Readability;
- Material Design Components;
- Visual Consistency;
- Visual Feedback During Data Updates;

The interface may contain different resources to represent the values, such as texts, cards, indicators, bars, graphic elements or other visual solutions that are considered adequate.
